WHAT TASK L ADDS
----------------
security/observer.py:
  * observe() is UNCHANGED (compatibility preserved).
  * observe_tiered(): Tier 1 (chunked semantic, Task H) + Tier 2
    (existing regex/content detector + NLI contradiction, Tasks I/J)
    run unconditionally on every chunk; Tier 3 (Task K judge) runs ONLY
    on chunks whose Tier-2 contradiction confidence exceeds the NAMED
    constant TIER3_CONTRADICTION_THRESHOLD (=0.60) -- no inline magic
    number.
  * ChunkDecision records, per chunk, which tiers ran and their outputs.
  * TieredObservation carries the per-response summary plus a
    per-episode tier3_invocations counter (reset_tier_counters()).
  * A security_state_chunks log line adds worst_chunk_deviation,
    contradiction_flagged_chunks and tier3_invocations. The base
    security_state line is emitted byte-for-byte unchanged, and the new
    chunk fields are APPENDED as named key=value pairs.

LOG-PARSER CHECK (required by the task): nothing in the repo parses the
security_state log line into fields -- experiments/show_security_logs.py
prints records verbatim and main.py prints its own computed summary, so
the unchanged base line plus an appended summary cannot break a reader.
experiments/show_security_logs.py was still extended to DISPLAY the new
chunk-level summary (a --tiered mode), so the tool reflects the new
fields.
